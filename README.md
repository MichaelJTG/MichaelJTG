## 🧩 Proyectos

### [ROSETTA](https://github.com/MichaelJTG/Rosetta) · Cumplimiento continuo multi-marco con IA

Traduce hallazgos técnicos (de un escáner, de un SOC, de un informe de auditoría en PDF o de un diff de código) en **evidencia de cumplimiento normativo**: qué control incumplen, con qué cita y cómo se mitiga.

- Siete marcos: **ENS, ISO 27001, NIS2, DORA, RGPD, NIST CSF y PCI-DSS**, con más profundidad en ENS e ISO 27001.
- LLM + RAG sobre el corpus normativo, con un agente validador. API en FastAPI y dashboard web.
- Usa Nuclei y Nmap como sensores e integra alertas de Wazuh.
- **0 % de controles inventados** en 89 casos de evaluación. La primera entrega obtuvo un **9/10** en el máster.

`Python` `FastAPI` `RAG` `LLM` `Docker` `GitHub Actions`

### Aegis OS · Entorno de aprendizaje en ciberseguridad

Aplicación self-hosted para organizar mi práctica en PortSwigger, HackTheBox y bug bounty: registro de intentos centrado en las hipótesis fallidas, biblioteca de principios, tutor con IA y generador de writeups.

`Docker` `Node.js` `Express` `SQLite` `React`

### [Resource Hub](https://github.com/DavidPachu1/ResourceHub-DAM) · Gestión de recursos empresariales

Proyecto colaborativo en el que me encargué del backend y la seguridad: autenticación stateless con JWT, hashing BCrypt, API REST con más de 15 endpoints y despliegue en AWS (EC2, RDS, S3) con CI/CD.

`Java` `Spring Boot` `Spring Security` `MySQL` `AWS` `Docker`
